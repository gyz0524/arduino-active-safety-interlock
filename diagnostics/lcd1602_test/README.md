# LCD1602 独立测试

这个测试只驱动 LCD1602，不使用点阵、触摸、摇杆或 SW-520D，用来判断 LCD 接线和对比度是否正确。

1. 在 Arduino IDE 中打开本目录里的 `lcd1602_test.ino`。
2. 保持 LCD 接线：RS→D2，E→D3，D4→D4，D5→D5，D6→D6，D7→D7。
3. LCD 的 RW 接 GND，VSS 接 GND，VDD 接 5V。
4. 上传后应显示两行：`LCD TEST OK` 和 `RS D2 E D3`。

结果判断：

- 能显示文字：LCD 硬件和接线基本正常，问题在主程序上传、端口占用或主程序运行环境；重新上传 `111.ino`。
- 仍只有一排方块：先不要接点阵和其他模块，按主对话中的 LCD 排查顺序检查电源、RW、VO、RS/E、D4-D7 以及 LCD 排针方向。
